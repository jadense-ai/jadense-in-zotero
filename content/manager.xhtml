上手指南

从读懂一篇文献开始，让 AI 参与你的阅读、理解与思考。

功能指南

开始之前

从 Zotero「工具 → Jadense → 打开攻玉工作台」进入，在「设置 → 功能配置」为各项功能选择攻玉模型或自己的模型。使用攻玉模型前，先到「设置 → 连接攻玉」生成并保存令牌；使用自己的模型（BYOK）时，先到「设置 → BYOK」添加服务商、API 密钥和模型，再回到功能配置选择它。

01 / 阅读文献

文献解析

先快速看懂论文在研究什么、怎么做、得出了什么结论，再回到 PDF 核对重要内容。

适合什么时候使用

  • 第一次接触一篇论文，想先判断它值不值得精读。
  • 准备组会或汇报，想快速整理研究问题、方法、结果和局限。
  • 论文较长、结构比较复杂，需要一份阅读提纲。

如何开始

  1. 在 Zotero 中打开要解析的 PDF，确认附件已下载且可以读取文字。
  2. 如需更换模型，到「设置 → 功能配置」选择可用的攻玉模型或已保存的 BYOK 模型。这里的选择不会改变对话和翻译模型。
  3. 点击 PDF 阅读器的「解析」（窄窗口先展开「阅读操作」菜单）。工作台显示解析进度，同时提取当前 PDF 的参考文献；需要中断解析时点击「停止」。
  4. 完成后先看摘要，再回到 PDF 批注和原文页面，核对重要结论是否有依据。

在哪里查看结果

「解析历史」按 PDF 展示每篇文献最近一次的结果。点击标题进入详情，在「解析总结 / 解析笔记 / 参考文献」之间切换；「打开原文」单独用于回到 PDF。需要整理成自己的笔记时，可在正文中选中需要的内容复制。

能够对应到原文位置的内容会写成 Zotero 批注，你可以继续编辑、筛选和导出。暂时无法放回 PDF 的内容，会保留在「解析笔记」中。解析结果和 AI 对话彼此独立。

解析参考文献

开始解析时，插件会同时整理论文末尾的参考文献。如果没有看到参考文献结果，可以打开「参考文献」标签，点击「提取参考文献」。暂停会同时暂停两项任务，但已经得到的内容会保留。

参考文献解析成功后，可以做什么

  1. 按标题、作者或 DOI 搜索，也可以按状态筛选，快速找到已核验、待核验或已经在文库中的条目。
  2. 点击「定位原文」回到这条引用在当前论文中的位置；需要继续找被引用的论文时，可以使用「搜索文献」或「原文链接」。
  3. 对于已核验的条目，选择可写入的文库和分类，就可以单条或批量「导入 Zotero」。文库中已经有的条目不会重复添加。
  4. 导入后，可以把它们作为后续阅读清单，追溯这篇论文的研究背景，或围绕选中的来源开启新的对话。

只有书目信息比较可靠的条目可以导入。遇到待核验条目时，可以先保留原始引用、手动搜索，或等核验完成后再处理。

遇到问题时

  • 扫描件、加密文件或尚未下载的附件可能无法提取正文。先检查 PDF 是否可读、可选中文字。
  • 长文按上限选取内容进行解析，不能将摘要视为已经覆盖整篇论文。
  • 生成中断或失败时，已经收到的文字会尽量保留并标明不完整。如果提示结果未保存，请在关闭窗口前选中并复制解析笔记。

可以先问自己三个问题：这篇论文解决什么问题？作者怎么验证？哪些证据支持结论？把解析结果当作阅读地图，最终判断仍要回到论文原文。

02 / 理解图表

图片解读

不用离开 PDF，就可以询问图片、公式、表格或示意图。能自动选中时用自动识别，需要精确选择区域时用手动截图。

自动识别：适合快速选中图片

自动识别使用 Zotero 提供的图片信息。PDF 文件内部的图片和排版方式比较复杂，部分图片可能出现轮廓错位，或只识别到一部分区域。这是自动选区可能遇到的情况，不影响你继续使用图片解读。

  1. 在 Zotero PDF 阅读器中，将鼠标移到可识别的图片上。出现绿色轮廓后，点击图片锁定选区。
  2. 选择「图片解读（开启新对话）」或「图片解读（追加在当前对话）」，插件会截取图片并发送解读请求。
  3. 在工作台阅读解读结果，继续提问，例如「图中的对照组支持了什么结论？」。

手动截图：自动识别的补充

自动识别没有反应、位置不准或区域不完整时，可以使用手动截图。公式、表格、图例、子图，以及其他需要看清局部细节的内容，也适合用手动截图。

  1. 让 PDF 阅读区域获得焦点，按默认快捷键 Ctrl + Alt + S；macOS 使用 ⌘ + Alt + S。
  2. 在同一 PDF 页面内拖动框选图片、子图或表格区域，再选择开启新对话或追加到当前对话。
  3. 按 Esc 或点击退出按钮离开截图模式。选错区域时，退出后再次按截图快捷键重新框选。

怎么选择

  • 绿色轮廓能完整跟随图片，并且包含需要的标签、坐标和图例时，使用自动识别。
  • 没有轮廓、轮廓错位、只选中局部，或想包含公式和表格时，改用手动截图。
  • 自动识别需要 Zotero 10.0.1 及以上版本的兼容阅读器；阅读器支持区域裁剪时，还可以使用手动截图作为补充。

选择哪一种对话

  • 开启新对话：适合开始读一张新图。自动关联当前文献的信息与可提取的 PDF 正文，作为解读背景。
  • 追加在当前对话：适合接着已有问题讨论，保留当前对话的标题、消息与已关联来源。

继续追问与设置

请为图片解读选择支持图片输入的模型。图片会显示在对应消息下方，可点击放大，并随对话保存在本机。追加新图后，后续追问会带上最近一张图；重新打开工作台后也可以继续查看和追问。旧版本未保存的图片需要重新识别或截图。

截图时尽量包含坐标轴、单位、图例和必要的图注。你可以问「每条曲线代表什么」「各组有什么差异」「这张图是否真的支持作者的结论」。数字和结论仍要结合原图与论文核对。

截图快捷键可在「设置 → 快捷键设置」修改并保存。发送图片解读时，所选图片会提供给你选择的 AI 服务。

03 / 读懂外文

翻译功能

阅读时可以只翻译当前需要的句子或段落，也可以处理整篇 PDF。两种方式适合的场景不同。

怎么选择

  • 选中翻译：适合查术语、看难句和理解关键段落，内容更集中，通常也更省 token。
  • 全文翻译：只在需要快速浏览整篇材料时考虑。它会处理大量文字，等待更久，也会消耗更多 token。

选中翻译

  1. 在 PDF 中选中需要翻译的文字。
  2. 点击选文浮动工具条中的「智能翻译」，或按 Ctrl + Alt + T（macOS 为 ⌘ + Alt + T）。
  3. 在翻译浮窗中查看结果。默认方向为「英文 → 简体中文」，可修改源语言和目标语言，也可将源语言设为「自动识别」，然后点击「重新翻译」。
  4. 需要带走译文时点击「复制译文」。

全文翻译

不建议把全文翻译作为常规阅读方式：它会处理很多页面，把大量文字交给模型，可能在不需要翻译的内容上浪费 token。想先了解重点时，建议先用「文献解析」或「选中翻译」。

  1. 打开 PDF 阅读器侧栏，切换到「全文 Markdown」，点击「提取原文」，生成可阅读的正文和图片。
  2. 提取完成后先阅读原文并选择目标语言；手动点击「翻译全文」，翻译当前保存的 Markdown 版本。
  3. 可以在翻译浮窗或详情中暂停、继续。已经完成的页面会保留，之后可以接着做；重启 Zotero 后需要手动点击继续。

翻译进行时，可以拖动或调整浮窗大小，也可以最小化或隐藏浮窗；隐藏后任务仍会继续。点击段落旁的「定位原文」可以回到 PDF 对应页面。

回看翻译历史

「解析历史」以文献汇总原文提取、全文翻译、选中翻译和解析成果。进入详情选择附件，通过「历史」回看各次结果。记录保存在本机，与 AI 对话分开。

「设置 → 常规」可以调整插件字号、翻译浮窗样式和背景透明度；「设置 → 功能配置」可以选择翻译功能使用的模型。

使用建议

  • 尽量选完整句子或较短段落，既给译文足够上下文，也避免一次发送太多文字。
  • 在翻译浮窗中修改源语言和目标语言，再点击「重新翻译」；语言修改只作用于当前选文。
  • 扫描 PDF 如果无法选中文字，先准备带有可读取文字的版本，再使用选中翻译。
  • 在「设置 → 快捷键设置」修改翻译快捷键后，点击「保存」生效。

04 / 带着问题阅读

AI 对话

围绕一篇或多篇文献提问，把文献信息、附件正文和引用选文放入同一段讨论。

开始一段对话

  1. 在工作台侧边栏点击「新对话」；也可在 PDF 阅读器顶部点击「提问」，直接创建以当前文献命名并关联来源的新对话。
  2. 展开「对话详情」，通过「关联条目」添加文献信息，或通过「关联文件」加入附件中可提取的正文。也可以将 Zotero 条目或附件拖入对话。
  3. 输入问题，点击「发送」或按 Ctrl / ⌘ + Enter。Enter 用于换行。
  4. 继续追问、复制回答，或点击「停止」中断生成。对话列表可切换已有讨论。

上传图片来提问

点击输入框下方的「上传图片」选择一张 PNG 或 JPEG，也可粘贴或拖入图片。发送前可以预览、移除或重新选择；支持只发图片，也可补充文字问题。上传图片使用 AI 对话模型，请选择支持图片输入的模型。

引用原文来提问

在 PDF 中选中文字后，点击顶部「引用」或选文工具条中的「引用选文」。选文会带着来源与页码加入当前输入草稿，补充问题后再发送。

选择模型与管理来源

在输入框下方选择攻玉内置模型或 BYOK 自配置模型。连接攻玉账号后，默认使用 deepseek-v4-flash-vision-exp，已有模型选择保持不变。受限模型会显示所需订阅档位，可更换可用模型或升级订阅。提供商与模型目录在「设置 → BYOK」中管理。

「对话详情」按文献分组展示来源，可以打开原文或解除关联。移除来源只影响当前对话，不会删除 Zotero 条目。附件正文有提取范围和长度上限，请留意来源中的读取状态与字数。

可以这样问

  • 这篇论文试图解决什么问题？方法与结论之间有哪些证据？
  • 比较已关联的两篇文献：研究假设、实验设计和局限分别是什么？
  • 解释这段引用中的概念，并指出还需要核对的原文依据。

对话历史保存在这台电脑的 Zotero 中。发送时会向所选 AI 服务提供问题、关联元数据和提取文本；普通文件关联不上传原文件，图片上传和图片解读会发送所选图片。

    Jadense in Zotero
    
      
    
        
    Jadense in Zotero 是攻玉学术的 Zotero 研究工作台扩展，将 AI 对话、选文翻译、PDF 图片解读和文献解析带到你的阅读流程中，帮助你在阅读、提问、整理来源和回到原文之间保持连续。
    
        
    连接攻玉学术后，你可以使用攻玉 AI，并将 Zotero 中选定的条目同步到攻玉收藏夹；也可以配置 BYOK，使用自己的模型服务。攻玉学术主应用面向科研阅读与知识管理，提供 AI 对话、文献与文件管理、收藏夹和工作空间等能力。本插件与主应用相互配合，同时保持独立安装、独立开源的 Zotero 客户端定位。
    
        
    如果 Jadense in Zotero 对你的研究工作有帮助，欢迎前往 GitHub 开源仓库点个 Star。你的支持会帮助我们持续改进插件与攻玉学术生态。
