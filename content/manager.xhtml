上手指南

从读懂一篇文献开始，让 AI 参与你的阅读、理解与思考。

功能指南

开始之前

从 Zotero「工具 → Jadense → 打开攻玉工作台」进入，在「设置 → 功能配置」为各项功能选择攻玉内置模型或 BYOK 自配置模型。使用攻玉时，先到「连接攻玉 → 连接配置」生成并保存令牌；使用 BYOK 时，先到「设置 → BYOK」添加提供商、API 密钥和模型，再回到功能配置选择模型。

01 / 阅读文献

文献解析

梳理论文的研究问题、方法与发现，把解读留在原文旁，方便边读边核对。

如何开始

  1. 在 Zotero 中打开要解析的 PDF，确认附件已下载且可以读取文字。
  2. 如需指定解析模型，先到「文献解析 → 解析配置」选择攻玉或已保存的 BYOK 模型。这里的选择独立于对话和翻译。
  3. 点击 PDF 阅读器的「解析」（窄窗口先展开「阅读操作」菜单）。工作台显示解析进度，同时提取当前 PDF 的参考文献；需要中断解析时点击「停止」。
  4. 完成后查看摘要，并回到 PDF 阅读对应的分类批注，核对论点与原文证据。

在哪里查看结果

「解析历史」保存文献信息和摘要。展开「查看解析笔记」可阅读详细备份，使用「复制笔记」带走内容；点击历史记录标题可重新打开对应的本地 PDF。

能够定位到原文的解析内容会写为 Zotero 原生批注，可以继续编辑、筛选和导出。无法定位或未成功写入的内容仍可在解析笔记中查看。解析不会创建 AI 对话。

解析参考文献

点击阅读器「解析」会同时提取当前 PDF 的参考文献。在「文献解析 → 参考文献」查看结果，也可在该页面选择其他 PDF。先按文字和排版规则提取，只有不确定局部才使用文献解析模型兜底；仅缺少 DOI 不会调用 AI。原始引用、编号、顺序、重复出现和待识别片段都会保留。

「识别待定片段」可重试局部识别；「跳过 AI，继续核验」仅取消 AI 并继续元数据核验。「暂停」停止整个任务；「统一重新核验」不会调用 AI。

核验仅使用 Zotero DOI 转换器和 Crossref，不调用 AI、不写文库。未验证条目没有操作按钮；DOI 还必须与原引用的题名、作者和年份匹配，才显示定位、原文链接及导入操作。选择可写文库和分类后，可导入单条或勾选的已验证条目。同库 DOI 重复时保留列表条目，但不重复创建；不下载附件。

遇到问题时

  • 扫描件、加密文件或尚未下载的附件可能无法提取正文。先检查 PDF 是否可读、可选中文字。
  • 长文按上限选取内容进行解析，不能将摘要视为已经覆盖整篇论文。
  • 生成中断或失败时，已收到的文字会尽量保留并标明不完整，不会写入 PDF 批注；若在批注写入阶段停止，已保存的批注会保留。若提示结果未保存，请在关闭窗口前复制笔记。

02 / 理解图表

图片解读

读懂图中的变量、趋势与结论。可以自动识别论文图片，也可以手动截取需要解读的区域。

自动识别

  1. 在 Zotero PDF 阅读器中，将鼠标移到可识别的图片上。出现绿色轮廓后，点击图片锁定选区。
  2. 选择「图片解读（开启新对话）」或「图片解读（追加在当前对话）」，插件会截取图片并发送解读请求。
  3. 在工作台阅读解读结果，继续提问，例如「图中的对照组支持了什么结论？」。

截图识别

  1. 让 PDF 阅读区域获得焦点，按默认快捷键 Ctrl + Alt + S；macOS 使用 ⌘ + Alt + S。
  2. 在同一 PDF 页面内拖动框选图片、子图或表格区域，再选择开启新对话或追加到当前对话。
  3. 按 Esc 或点击退出按钮离开截图模式。选错区域时，退出后再次按截图快捷键重新框选。

没有出现自动识别轮廓时，可以直接使用截图识别。自动识别依赖阅读器提供图片结构，Zotero 10.0.1 及以上版本支持此能力；截图仍需阅读器支持区域裁剪。

选择哪一种对话

  • 开启新对话：适合开始读一张新图。自动关联当前文献的信息与可提取的 PDF 正文，作为解读背景。
  • 追加在当前对话：适合接着已有问题讨论，保留当前对话的标题、消息与已关联来源。

继续追问与设置

图片解读需要支持图片输入的模型。图片会显示在对应消息下方，可点击放大，并随对话保存在本机。追加新图后，后续追问携带最近一张图；重新打开工作台后也可继续看图和追问。旧版本未保存的原图需要重新识别或截图。

截图快捷键可在「设置 → 快捷键设置」修改并保存。图注不一定能被识别，请结合原图核对数字、坐标和 AI 的推断。

03 / 跨语言阅读

实时翻译

选中一段原文，在阅读器内直接查看逐步生成的译文，保持阅读节奏。

翻译选中的文字

  1. 在 PDF 中选中需要翻译的文字。
  2. 点击选文浮动工具条中的「智能翻译」，或按 Ctrl + Alt + T（macOS 为 ⌘ + Alt + T）。顶部工具条提供「全文翻译」。
  3. 在翻译浮窗中查看结果。默认方向为「英文 → 简体中文」，可修改源语言和目标语言，也可将源语言设为「自动识别」，然后点击「重新翻译」。
  4. 需要带走译文时点击「复制译文」。

全文翻译

点击阅读器「全文翻译」，按文章语言设置，使用实时翻译模型处理所有可提取文字的页面。浮窗可拖动、调整大小、最小化或隐藏；隐藏后继续执行。每段独立的「定位原文」可跳回来源，选择译文不会触发跳转。

可在浮窗或详情暂停、继续；重启 Zotero 后需手动继续，已完成分块会保留。空白、扫描或读取失败页会明确标记，并显示部分完成。附件变化后需重新建立任务。两种翻译浮窗均可拖动标题移动、拖拽任意边缘或角落缩放；左下角「外观」展开样式与背景透明度菜单，设置在两种浮窗间共用。

回看翻译历史

翻译历史默认显示摘要。点击选文记录展开原文和译文；点击全文记录进入按页详情，可复制、续译、重新翻译或删除。记录在本地独立保存，不属于 AI 对话。出现保存失败提示时，请在关闭 Zotero 前复制会话结果。

「设置 → 常规」可调整界面字号 12–24px（默认 13px）、翻译浮窗样式和背景透明度，即时作用于插件界面，PDF 原文与 Zotero 自有界面不变。

使用提示

  • 先选中文字，再触发翻译；扫描件如果无法选文，需要先准备可提取文字的 PDF。
  • 在翻译浮窗中修改源语言和目标语言，再点击「重新翻译」；语言修改仅作用于本次选文。
  • 翻译使用「设置 → 功能配置」中独立选择的实时翻译模型。
  • 在「设置 → 快捷键设置」修改翻译快捷键后，点击「保存」生效。

04 / 带着问题阅读

AI 对话

围绕一篇或多篇文献提问，把文献信息、附件正文和引用选文放入同一段讨论。

开始一段对话

  1. 在工作台「对话」页点击「新建对话」；也可在 PDF 阅读器顶部点击「提问」，直接创建以当前文献命名并关联来源的新对话。
  2. 展开「对话详情」，通过「关联条目」添加文献信息，或通过「关联文件」加入附件中可提取的正文。也可以将 Zotero 条目或附件拖入对话。
  3. 输入问题，点击「发送」或按 Ctrl / ⌘ + Enter。Enter 用于换行。
  4. 继续追问、复制回答，或点击「停止」中断生成。对话列表可切换已有讨论。

上传图片来提问

点击输入框下方的「上传图片」选择一张 PNG 或 JPEG，也可粘贴或拖入图片。发送前可以预览、移除或重新选择；支持只发图片，也可补充文字问题。上传图片使用 AI 对话模型，请选择支持图片输入的模型。

引用原文来提问

在 PDF 中选中文字后，点击顶部「引用」或选文工具条中的「引用选文」。选文会带着来源与页码加入当前输入草稿，补充问题后再发送。

选择模型与管理来源

在输入框下方选择攻玉内置模型或 BYOK 自配置模型。连接攻玉账号后，默认使用 deepseek-v4-flash-vision-exp，已有模型选择保持不变。受限模型会显示所需订阅档位，可更换可用模型或升级订阅。提供商与模型目录在「设置 → BYOK」中管理。

「对话详情」按文献分组展示来源，可以打开原文或解除关联。移除来源只影响当前对话，不会删除 Zotero 条目。附件正文有提取范围和长度上限，请留意来源中的读取状态与字数。

可以这样问

  • 这篇论文试图解决什么问题？方法与结论之间有哪些证据？
  • 比较已关联的两篇文献：研究假设、实验设计和局限分别是什么？
  • 解释这段引用中的概念，并指出还需要核对的原文依据。

对话历史保存在这台电脑的 Zotero 中。发送时会向所选 AI 服务提供问题、关联元数据和提取文本；普通文件关联不上传原文件，图片上传和图片解读会发送所选图片。
