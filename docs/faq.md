# 常见问题（FAQ）

[返回 README](../README.md) · [使用指南](usage-guide.md) · [Zotero 入门](zotero-guide.md)

## 项目免费吗？需要付费或赞助才能使用吗？

插件可免费下载，允许个人非商业自用、学习与非商业研究；不要求赞助。AI 服务费用另算：BYOK 由你选择的服务商计费，攻玉模型按账号订阅、权限与积分规则提供。免费插件不意味着无限免费模型额度。详见 [LICENSE](../LICENSE)。

## 必须注册攻玉账号吗？

不需要。BYOK 可独立使用问答、翻译、解析和图片解读；模型需支持对应输入。使用攻玉模型、账号功能或向攻玉上传文献时才需要连接攻玉。

## BYOK 怎么配置？Base URL 应该填什么？

在「设置 → BYOK」添加提供商，填写协议、API 基础地址和密钥，再添加模型。Base URL 不要填写聊天网页或完整 `chat/completions`、`responses`、`messages` 端点，插件会自动追加。完整字段说明和步骤见[使用指南](usage-guide.md#byok-provider)。

保存后在「设置 → 功能配置」选择 AI 对话模型。默认其他功能跟随当前对话模型；要分别选择翻译、解析与图片模型，关闭「自动跟随当前对话模型」。

## 有聊天产品订阅，可以直接当 API Key 用吗？

不能把网页登录密码或订阅名称填进 API Key。需要服务商实际提供的 API 密钥、支持的协议及可调用模型；是否包含 API 额度以该服务商账户规则为准。攻玉插件令牌仅用于「连接攻玉」，不是 BYOK 密钥。

## 连接测试失败或配置后无法使用，怎么办？

| 现象 | 建议检查 |
| --- | --- |
| 401 / 鉴权失败 | 密钥是否有效、复制时是否多出字符、是否属于该服务商 |
| 403 / 权限不足 | 账户是否有该模型权限，攻玉令牌是否缺少所需授权 |
| 404 / 模型或接口不存在 | Base URL 是否重复端点、协议是否受支持、模型 ID 是否正确 |
| 429 / 额度或频率限制 | 服务商余额、额度和请求限制，等待后再操作 |
| 网络错误 / 超时 | 当前电脑能否访问 API 地址、代理配置及服务商状态 |
| 测试成功但翻译失败 | 功能实际使用的模型、输出限制、PDF 是否能提取文字 |
| 图片请求失败 | 模型是否支持图片，服务商是否支持相应图片协议 |

这些是排查方向，最终以服务商返回的错误说明为准。不确定请求是否完成时先查看结果或账单，避免连续重复发送。

## 为什么功能模型选择器不能编辑？

通常是开启了「自动跟随当前对话模型」。关闭后可独立配置。受限攻玉模型会显示所需订阅档位；充值积分不等于解锁模型。

## PDF 可以打开，为什么无法翻译或解析？

扫描件可能只有图片，没有可提取正文。先检查能否选中并复制正常文本；全文翻译可使用内置本机 OCR。加密、提取异常或缺失的本地附件也可能影响处理。首次 OCR 会下载本机运行环境和模型，详见 [OCR 安装说明](local-ocr.md)；识别后的正文发给所选翻译服务。插件不生成保留原排版的双语 PDF。解析和译文应与原文核对。

## 为什么图片没有自动识别框？

自动识图依赖 Zotero 10.0.1+ 兼容阅读器提供的图片结构。可改用截图快捷键手动框选；如果宿主不支持原生裁图，使用对话图片上传。图片解读仍需要支持视觉输入的模型。

## 历史会上传吗？API Key 存在哪里？

设置、对话、图片附件、翻译和解析历史保存在本机 Zotero profile；API Key 和插件令牌也在其中，不应分享整个 profile。使用模型时，请求所需的文字、文献上下文与图片会发送给所选服务，不能把本地历史理解为完全离线。

BYOK 模型请求直接发往配置的提供商；已连接攻玉的账号功能、参考文献核验和自动更新仍可能联网。插件对话不会创建攻玉网页端的持久对话。详细操作数据去向见 [README](../README.md#数据与凭据) 和 [SECURITY](../SECURITY.md)。

## 如何升级？升级后设置和历史还在吗？

相同 `.cn` 插件身份可直接安装新版，保留已有设置与本地历史。使用旧 `.com` 身份时须先禁用旧插件，再安装新版，不能同时启用。不要删除 Zotero profile。完整步骤见 [README](../README.md#upgrade)。

## 能商用、转售或收费代安装吗？

当前非商业许可禁止商业用途，包括出售插件、收费代安装或托管、付费产品集成和商业组织业务使用；不收费也不自动等于非商业。个人非商业自用、学习与研究可以使用。商业用途需另行取得权利人书面授权；赞助不构成商业授权。历史 MIT 版本及第三方组件仍按其原许可处理，具体边界见 [LICENSE](../LICENSE)。

## 如何支持项目？可以留言、加入赞助名单吗？

可以 Star、分享、提交问题、完善文档或贡献代码，也可以通过[独立赞助页](../support/README.md)中的支付宝或微信收款码自愿赞助。付款备注可写「昵称｜留言｜同意公开昵称」，不希望公开则写「匿名」或「不公开」。未来制作名单仅使用明确同意公开的昵称与留言，不公开真实姓名、账号或交易号。详见 [如何支持我们](../README.md#support)。
