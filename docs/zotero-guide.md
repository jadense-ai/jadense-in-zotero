# Zotero 入门指南

## Zotero 是什么？

Zotero 是用于收集、整理、阅读和引用研究资料的免费文献管理工具。它管理论文标题、作者、DOI 等信息，也能保存 PDF、笔记与批注，帮助你在写作中插入引用和生成参考文献。基本能力见 [Zotero 官方入门](https://www.zotero.org/support/quick_start_guide)。

Jadense in Zotero 是安装在 Zotero 桌面端中的 AI 阅读插件，增加论文问答、翻译、解析与图片解读。安装插件后仍使用原有 Zotero 资料库。

## 先认识三个概念

| 名称 | 含义 | 使用插件时的关系 |
| --- | --- | --- |
| 文献条目 | 一篇论文的标题、作者、期刊、DOI 等元数据 | 用来关联论文、核对来源与导入引用 |
| PDF 附件 | 条目下实际保存或链接的论文文件 | 正文翻译与解析需要可访问、可提取文字的 PDF |
| 分类与笔记 | 分类用于组织文献，笔记用于记录阅读所得 | 同一条目可归入多个分类，不需要重复导入 |

只有标题和 DOI，并不代表本机已有全文。先展开条目、双击 PDF，确认可以阅读并选中文字。

## 从零开始

1. 从 [Zotero 官网](https://www.zotero.org/download/)安装桌面程序。插件当前声明支持 Zotero 8–10；具体测试范围见 [README](../README.md)。
2. 可安装官网提供的 Zotero Connector 浏览器扩展，在论文网页保存条目；也可以用 Zotero 的标识符添加功能输入 DOI，或导入已有 PDF。
3. 核对条目的标题、作者与 DOI；将 PDF 作为对应条目的附件，避免论文与附件错配。
4. 建立一个课题分类，放入相关条目，双击附件开始阅读。
5. 按[插件使用指南](usage-guide.md)安装 XPI、配置模型，先尝试一段选文翻译。

Zotero Connector 与 Jadense 插件分别安装在浏览器和 Zotero 桌面端。安装 Connector 不会自动安装 Jadense 插件。
