# 支持 Jadense in Zotero

[返回项目首页](../README.md) · [English README](../README.en.md)

感谢你使用 Jadense in Zotero。你的支持将帮助我们持续改进插件、修复问题和完善使用文档。

## 微信 / 支付宝

赞助完全自愿，金额由你决定。打开微信或支付宝扫描对应收款码；点击图片可查看原图。付款前请核对所选平台及支付应用内显示的收款人信息。

## 留下昵称与留言

付款时可备注：**昵称｜想说的话｜同意公开昵称/留言**。

例如：`小玉｜感谢你们持续维护｜同意公开昵称和留言`。如果不希望公开，可写「匿名」或「不公开」；没有明确同意的记录默认不展示。无需在公开 Issue 中上传付款凭证或交易号。

## 未来赞助名单

后续可根据自愿公开的备注整理赞助名单，目前尚未建立，也不承诺自动收录。仅展示明确同意公开的昵称和留言，不公开付款真实姓名、账号或交易信息。

## 其他支持方式

- 在 [GitHub 项目](https://github.com/jadense-ai/jadense-in-zotero)点亮 Star，分享给需要的朋友。
- 通过 [Issues](https://github.com/jadense-ai/jadense-in-zotero/issues)反馈可复现问题和建议。
- 完善图文指南，或按[贡献指南](../CONTRIBUTING.md)提交改进。

## 赞助与使用权限

赞助不是使用门槛，不购买模型额度、攻玉订阅、积分、商业授权或优先支持承诺。插件使用遵守 [LICENSE](../LICENSE)，模型与攻玉服务费用另计。
